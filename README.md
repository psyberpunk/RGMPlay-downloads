# RGM Play — Descargas

Descarga la app **RGM Play** para tu dispositivo.

## Última versión

Ve a **[Releases](../../releases/latest)** y descarga el APK que corresponda:

| Archivo | Dispositivo |
|---|---|
| **RGMPlay-2.5.0-arm64.apk** | Teléfono / tablet 64-bit (la mayoría) |
| **RGMPlay-2.5.0-arm32.apk** | Teléfono 32-bit (equipos antiguos) |
| **RGMPlay-1.12.0-tv.apk** | Android TV / TV Box |

## Instalación

1. Descarga el APK de tu dispositivo.
2. Activa **"Instalar apps de fuentes desconocidas"** (Ajustes → Seguridad / Apps).
3. Abre el APK descargado e instala.
